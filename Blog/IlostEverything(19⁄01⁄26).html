I lost Everything...

(19/01/26)


So it would seem I made an oopsie, a blunder or maybe even a giant steaming fuck up. I lost everything. Not EVERYTHING everything but it damn well feels like it. I finally finished my new PC a few days ago in spite of the RAMpocalypse and the ever rising cost of litterally all Hardware thanks to this A.I. bullshit and wanted to finally commit to dual booting on my Desktop. As one would do in this situation I backed up all my important files to another drive before I tinkered with anything OS related, in my infinite wisdom I decided that it would be a short process and I'd only need that 1 backup. Cut to now where my 'Content' folder. Half a decade of Videos, Streams, Models, Art and who knows what else including a big video I was finally working on in hopes of getting back into the YouTube scene, is completely gone. To make all matters worse by this point I had partitioned the Drive, installed Fedora and a bunch of games so there's pretty much no way that the allocated space wasn't overwritten despite my best efforts to check. What frustrates me the most (other than the actual loss of files that held me in literal tears) was the fact that in the SAME COPY OPERATION I moved 2 other folders that were still present in BOTH Windows and Fedora so the folder that was most important to me just decided to commit digital suicide.

It was idiotic of me to think that a single backup would suffice but I knew that worst case scenario I had a complete backup of my old laptop stored on Google Drive from before I switched to Debian which would have a slightly outdated version of the folder, but alas going into the folder that SHOULD have held that backup I was greeted with nothing. I did manage to find 1 backup of the folder on said drive but that was an even OLDER copy dated to 2023... (fuck that should not be 3 years ago now that's meant to be like 5 years away) so there wasn't actually much of value there. I wanted a fresh start in the Online space almost separate from my old self but this was definitely in no way ideal, no recovery tools worked and the one that did decided to pull over 200GB worth of files separated into 3000+ folders instead of just the Desktop directory I KNEW held the folder and it wasn't going to be feasible for me to sift through that... Thankfully a friend of mine is hooking me up with a new ref sheet free of charge, I feel like a giant asshole asking for free shit but money is kinda tight right now so I'm kind of left with no choice if I want to continue pushing myself back into Content Creation, but when I'm better off money wise hopefully I can pay at least something small to repay them.

If it wasn't obvious this wasn't exactly how I wanted to start the year (or this blog) but that's just been my luck as of late, so no "HEY EVERYONE LOOK AT THIS COOL THING HERES SOME UPDATES ABOUT MY LIFE" this time, or at least maybe not as positive as I'd had hoped LMAO. I'll slowly be working towards getting myself back off the ground again so that I can start making videos again, that Windows install is completely wiped now that I've thrown in the proverbial towel so it's just to a little more repartitioning, installing Windows 11 (ew) and then debloating Windows 11 (still ew but I need to play Fortnite somehow (fuck you Epic just enable EAC on Linux)). I'm also not sure I'll stick with Fedora, or KDE for that matter. I love KDE a lot but I've been hearing a lot of complaints about how bloated it is lately with all the dependencies and during that whole recovery attempt seeing a billion files from web cache and old Minecraft textures and a billion god damn things I swear I've never seen before. It's made me want my systems to be as cut down and streamlined so skinned XFCE might be the way to go for me, although I've never liked the default setup so we'll see how that goes if I jump ship. As for Fedora I'm just kinda so used to using apt as my package manager and I don't care for the 3 partitions for one installation deal (wow a lot of partitioning talk today).

I think that's everything for this time, I'll try and keep this blog as updated as I can now that I've officially started working on it, love y'all and please learn from me and invest in a NAS system with regular backups.
